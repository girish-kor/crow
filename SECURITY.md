# Security Policy

## Supported Versions

Security updates are applied to the latest release line.

## Reporting a Vulnerability

If you discover a security issue, please report it privately before disclosing
it publicly.

1. Open a private security advisory in GitHub (preferred), or
2. Contact maintainers directly via a private channel.

Please include:

- A clear description of the issue
- Reproduction steps or proof of concept
- Potential impact
- Suggested remediation, if known

We will acknowledge reports promptly and work on a fix as quickly as possible.
