# CROW — Deterministic Node.js Backend Code Synthesis Engine

CROW is a pattern-based, deterministic code generation engine for Node.js backends. It converts natural-language intent strings into production-ready Express or Fastify backend modules using TF-IDF pattern ranking and AST-based code synthesis.

## Quick Start

```bash
npm install
npm run seed       # Generate the pattern dataset (5,000 entries)
npm run dev        # Show CLI help
```

## CLI Usage

```bash
# Generate a user CRUD API with JWT auth
node cli/index.js generate "create user API with JWT auth"

# Generate using specific framework / validation / auth
node cli/index.js generate "build product API" --framework fastify --validation zod --auth apikey

# Dry-run: print code without writing a file
node cli/index.js generate "create order API" --dry-run

# List patterns
node cli/index.js list-patterns "user"

# Show dataset statistics
node cli/index.js stats

# Validate a generated file
node cli/index.js validate generated/user.express.router.js
```

## Architecture

```
intent string
     │
     ▼
intentParser.js    — tokenise & extract: action, resource, framework, validation, auth, db, features
     │
     ▼
patternSelector.js — TF-IDF + cosine similarity ranks corpus → top-N patterns
     │
     ▼
codeGenerator.js   — @babel/types AST construction + @babel/generator → JS source
     │
     ▼
formatter.js       — Prettier formatting
     │
     ▼
generated/*.js     — Runnable Express / Fastify router module
```

## Dataset

The dataset lives at `patterns/dataset.json` (generated, not committed to VCS).

- 3,000–50,000 entries (default: 5,000)
- Each entry: `{ id, intent, action, resource, framework, validation, auth, db, schema, output, constraints }`
- Deduplicated by composite key
- Edge cases included (missing fields, invalid schemas, nested objects)

## CI/CD

GitHub Actions workflow (`.github/workflows/ci.yml`):
1. Install dependencies (`npm ci`)
2. Lint source files (`npm run lint`)
3. Seed dataset (`npm run seed`)
4. Run unit tests (`npm test`)
5. Validate generation output (`npm run validate`)

Runs on Node 18.x and 20.x.

## Release Process

Use GitHub Releases for source distribution and release notes, and npm for install/run.

1. Update `package.json` version.
2. Add an entry to `CHANGELOG.md` under the new version.
3. Commit and push changes.
4. Create and push a version tag matching `package.json`:

```bash
git tag v1.0.1
git push origin v1.0.1
```

5. The release workflow (`.github/workflows/release.yml`) will:
     - verify tag version equals `package.json` version,
     - run lint/test/validate checks,
     - create a GitHub Release with autogenerated notes,
     - attach `CHANGELOG.md` to the release.

Publish npm separately after release checks pass:

```bash
npm publish
```
